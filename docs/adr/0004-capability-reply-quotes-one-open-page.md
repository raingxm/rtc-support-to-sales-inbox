# 产品能力的回复只摘打开的那一页

回复里的产品能力和操作步骤使用文档原句：从刚打开的一页抄下一句，并给出该页地址。一句只来自一页。两页说法不同时，回复不把它们合成一句更顺的话。打不开页面时，回复不回答是否，也不写步骤。

TRTC 的两页对云录制能否存到 AWS 说法不同。[On-Cloud Recording](https://trtc.io/document/45169) 写目前只能存到腾讯云 COS 或 VOD，第三方存储还是计划。 [CreateCloudRecording](https://trtc.io/document/46960) 写可以存到 VOD、COS 或 AWS。合成一句会让客户无法打开同一页核对。
