# 系统先回复可以回答产品能力

客户看见的第一条回复可以说明产品能不能做某件事，例如云录制。试点、迁移和报价仍然要支持人员确认之后才是商机。

只追问、不回答产品能力时，客户缺少继续问下去的理由。回复里直接告诉客户会有人接手试点，则在商机确认之前就向客户做了商业承诺。

同一条回复可以追问试点或迁移的事实。它不告诉客户负责人已经排好，也不告诉客户商机已经成立。

不维护一份自有能力清单。客户点名 Twilio 或 Agora 时，产品能力来自那一家的公开文档。客户没有点名厂商时的出处见 [0003](0003-unnamed-vendor-defaults-to-trtc.md)。回复要写出是哪一家。Twilio Skills 和 Agora Skills 是给编程代理写集成用的，不作为客户回复的依据。

确认商机也不生成回复。客户要知道有人跟进，只有支持人员亲手写一条回复。
