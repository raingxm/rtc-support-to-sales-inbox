# 客户写下 LiveKit 时，先问是哪一个产品

客户写下的名字对不上 Twilio、Agora、TRTC 或 TUILiveKit 时，回复先问客户指的是哪一个。问句给出客户写下的那家公司，以及 TRTC 与 TUILiveKit。客户写下 LiveKit 时，两个选项是 LiveKit 与 TUILiveKit。这条回复不回答产品能力。客户确认某家公司之后，产品能力来自该公司的公开文档。打不开页面，就不回答是否。

LiveKit 是另一家公司。trtc.io 上没有名为 LiveKit 的 TRTC 产品。名称接近的 TRTC 产品是 TUILiveKit，一个直播界面组件。TRTC 的站点把 LiveKit 当作另一个产品来比较。
